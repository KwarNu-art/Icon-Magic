# Icon-Magic — Cyber Spectrum

Original free **SnowBoard** icon theme: dark cyber / terminal aesthetic.

**Not** a jailbreak. **Not** SnowBoard itself. Requires [SnowBoard](https://www.sparkdev.me) (`com.spark.snowboard`).

## Status

| Item | State |

| Offline CLI fallback generator | **Build-tested** |

## Variants

- **IconMagicCyberSpectrum** — multicolor accents  
- **IconMagicCyberSpectrum-Green** — terminal green  
- **IconMagicCyberSpectrum-Blue** — electric blue  

## Quick build

```bash
python3 -m pip install Pillow
python3 tools/render_icons.py
python3 tests/test_theme.py
python3 tools/build_packages.py
```

Artifacts: `packaging/dist/*.deb` + `.sha256`

## Install (device)

1. Install **SnowBoard** from SparkDev.  
2. Install the matching `.deb` (rootful `iphoneos-arm` or rootless `iphoneos-arm64`).  
3. Settings → SnowBoard → enable **IconMagic Cyber Spectrum** (icons).  
4. Respring if SnowBoard asks.

## Offline extra icons

```bash
python3 tools/generate_from_manifest.py path/to/apps.json -o ./my-IconBundles
```

Copy generated `*-large.png` into the theme’s `IconBundles` (or rebuild a package).
